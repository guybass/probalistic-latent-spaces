# Paper-replication harnesses

This directory connects the project's research program to a persistent Codex
paper-replication workflow. Each paper gets an isolated workspace whose files,
not the chat transcript, are the system of record.

The initial case study is
[`predictive-geometric-agreement`](predictive-geometric-agreement/README.md), an
independent audit of this repository's own manuscript. It has already been
bootstrapped and its LaTeX source inventoried. It intentionally remains in
paper-intake until the manuscript's computational and proof-audit targets are
fully enumerated.

Use the installed `paper-replication` Codex skill for future external papers.
Keep paper assets reference-only, choose acceptance rules before examining a
candidate result, record every substantive run through the wrapper, and do not
claim completion until the harness gate passes.
